## 1. Strategy Summary

This pass strengthens the authority graph after Phase 2 cluster consolidations (certificate, lab/natural, fluorescence). The goal was not to link every article to every destination, but to add **natural, context-fit links** and **light related-array cleanup** so users, Google, and AI systems can see clear hierarchy:

**Education → Tool (Diamond Studio / Diamond Intelligence) → Trust (The House / Our Approach / GG) → Conversion (Concierge)**

Priority order followed in execution:

1. Certificate/report flagship (`how-to-read-a-diamond-certificate`)
2. Lab vs natural flagship (`natural-vs-lab-diamonds`)
3. Fluorescence flagship (`what-is-diamond-fluorescence`)
4. Diamond Intelligence (`/diamond-intelligence`)
5. Diamond Studio (`/diamond-studio`)
6. Concierge (`/concierge`)
7. Trust (`/the-house`, `/our-approach`, `why-work-with-a-graduate-gemologist`)

Copy changes were minimal: short phrases or sentences only, varied anchor text, no robotic “for more information” patterns.

- **Proposal planning cluster** (7 articles) — local romance/logistics focus; low fit for cert/lab/fluorescence flagships
- **Light performance deep dives** — already link cut hubs, DI, or Our Approach where appropriate
- **Shape guides** — already include Diamond Studio; no cert/fluorescence context without stuffing
- **Fluorescence merge candidates** — already point to flagship from Phase 2.3B
- **Certificate satellites** (GIA, IGI, GCAL, HRD, AGS, are-all-certificates) — already hub to certificate reader
- **Fluorescence satellites** (when improves/bad, chart, strong blue, etc.) — already hub to fluorescence flagship
- **Lab satellites** (`are-lab-diamonds`, `do-lab-grown-certificates`) — already cross-link cluster
- **Flagship articles themselves** — self-linking avoided except related cleanup on `natural-vs-lab-diamonds`
- **Thin definition pages** (brilliance, scintillation, fire, etc.) — no report/buying context without expanding scope
